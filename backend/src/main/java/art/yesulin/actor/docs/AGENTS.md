# 배우 프로필 규칙

최상위·작업 영역 공통 규칙을 적용하고 이 폴더의 README에서 해당 정책을 선택한다.

- 실제 HTTP 형식은 `backend/docs/api.md`, 입력 허용 범위는 DTO와 도메인 구현을 기준으로 한다.
- 선택 항목의 빈값을 실제 숫자 0과 혼동하지 않는다.
- 브라우저 검증으로 서버 검증을 대신하지 않으며 오류 필드와 복구 방법을 표시한다.
- 탭 전환이나 저장 응답 때문에 저장 중 사용자가 새로 입력한 값을 덮어쓰지 않는다.
- 평가·문제 집계·미사용 항목 점검은 공통 `docs/agent-review.md`를 따른다. 추가 전체 평가는 요구하지 않는다.
