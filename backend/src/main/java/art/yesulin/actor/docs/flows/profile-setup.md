# 배우 프로필 작성·공개

1. 공개 헤더의 배우 계정 메뉴는 마이페이지로 이동한다.
2. 내 프로필에서는 기본정보 → 사진 → 배우 페이지 순서로 시작한다. 추가정보와 영상은 선택 항목이다.
   기본정보는 이름·생년월일·성별부터 표시하고, 지원서용 키·몸무게·연락처·이메일·거주 지역은 펼쳐 입력한다.
   모두 채우지 않아도 저장할 수 있지만 이름·성별·생년월일은 페이지 공개에 필요하다.
3. 다음 단계로 진행할 때 변경한 정보는 기존 프로필 API로 저장하고 성공한 뒤 이동한다.
   실패하면 작성값을 유지한다. 일반 저장은 기존 최초 공개 안내를 유지하되,
   저장 응답 또는 공개 조건 조회를 기다리던 중 새로 작성한 값이 있으면 안내를 열거나 표시 기록을 남기지 않는다.
4. 사진 추가·삭제·공개 범위·대표·순서는 사진 탭 한곳에서 즉시 저장한다. 새 사진은 비공개로 시작하며,
   공개 사진을 한 장 이상 고르면 다음 단계로 갈 수 있다. 앞뒤 이동 버튼은 모바일과 키보드에서도 사용할 수 있다.
   페이지 대표 지정은 이미 공개로 설정한 사진을 첫 공개 사진 위치로 옮긴다. 비공개 사진을 자동으로 공개하지 않는다.
   순서는 같은 보관함을 공유하며 보관함 첫 사진은 지원서 대표, 첫 공개 사진은 페이지 대표다.
5. 배우 페이지에서는 아이디·공개 사진 장수를 확인하고 나머지 공개 항목·영상은 펼쳐 설정한다.
   사진 변경은 사진 탭으로 연결한다. 공개 조건이 부족하면 해당 입력 위치로 이동할 수 있다.
   저장하지 않은 기본·추가정보 또는 아이디가 있으면 공개를 막고 저장을 안내한다.
6. 미리보기는 화면 내에서 전환하고 서버가 공개 범위를 적용한 저장본만 사용한다. 미저장값은 반영되지 않음을 안내한다.
   입력 폼을 유지해 작성값·아이디·펼친 항목이 사라지지 않게 하고, 좁은 화면에서는 보기 전환 전 스크롤 위치로 복귀한다.
   넓은 화면에서는 입력과 미리보기를 나란히 보여 준다. 미리보기 자체는 저장·공개를 실행하지 않는다.
7. 공개 API가 성공하고 공개 상태·아이디를 받은 뒤 완료 화면에 페이지 링크와 같은 주소의 QR·복사·공유를 제공한다.
   일부 공개 사본 생성 실패는 완료 화면에 알리고 사진 탭의 재시도로 연결한다.
   QR 생성·복사·공유 실패는 별도로 안내하며 공개 성공을 취소하지 않는다.
   공개 조건·14세 기준·잠금·공개 사본·매 공개 동의는 기존 계약을 유지한다.

단계 이동·설정 조작 자체를 프로필 저장 성공으로 기록하지 않는다. PDF로 넣은 정보도 프로필 API 저장 성공 뒤에만 기존 저장 이벤트를 기록한다.
