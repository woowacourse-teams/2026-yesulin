# 프로필 숫자·생년월일 입력

프로필 기본정보는 항목을 비워 저장할 수 있다. 키·몸무게는 입력했을 때 양의 정수이며,
생년월일은 실제 달력 날짜이고 한국 시간 기준 미래가 아니어야 한다.
HTTP의 빈 항목은 null이며 UI의 빈 숫자 입력을 0으로 표시하지 않는다.

생년월일 입력은 숫자 8자리를 사용하고 완성한 값은 `YYYY-MM-DD`로 저장한다.
미완성·존재하지 않는 날짜·미래 날짜는 입력 종료와 저장 시 확인한다.
오류 설명을 입력란에 연결하고 저장 시 오류가 있으면 기본정보 탭의 해당 입력란으로 이동한다.
선택 항목을 비운 경우는 날짜 오류로 취급하지 않는다.

날짜 유효성·미래 날짜 허용 범위는 기존 `UpdateProfileBasicInformationRequest`의
`LocalDate` 및 `@PastOrPresent` 계약에 맞춘다. 서버의 검증도 유지한다.

## 경력 연월

- 경력 자체는 선택이지만 새로 추가하거나 수정하는 경력은 연도·월·작품명·배역이 필수다. 월은 1~12 정수다.
- 월이 없던 기존 경력은 그대로 유지·삭제·순서 변경할 수 있다. 연도·작품명·배역·장르를 바꾸면 월이 필요하다.
  서버는 기존 경력과 비교하며 같은 항목의 월 없는 복제를 허용하지 않는다.
- 저장된 옛 경력과 제출 스냅샷의 월은 null로 보존한다. 마이그레이션에서 임의 날짜를 채우지 않는다.
- 공개 페이지·미리보기는 월이 있으면 YYYY.MM, 과거 월 미상은 YYYY다. 분야별 연월 최신순이며 미상 월은 같은 해 마지막이다.
- 지원서에 새로 제출하는 경력은 월을 선택해야 한다. prefill·초안에서 월을 읽지 못해도 입력값을 지우지 않고 보완을 안내한다.
- PDF의 명확한 단일 연월만 채운다. 연도만 있거나 기간이 모호하면 월을 비워 직접 선택하게 한다.
