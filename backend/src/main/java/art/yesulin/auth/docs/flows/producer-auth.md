# 공연사 가입과 인증 복구

회원가입은 `PENDING` 계정을 저장한 뒤 인증 메일을 요청하고, 프론트가 비밀번호 로그인으로 세션을 만든다.
메일은 5분 유효한 6자리 코드이며 재전송 시 기존 발급 정보를 교체한다. `ACTIVE` 전환은 이메일 인증 또는 운영자 수동
활성화로만 수행한다. 미인증 세션으로는 프로필과 메일 재전송만 허용한다.

코드는 가입/로그인한 `PENDING` 공연사 세션의 회원에게만 검증한다. 원문은 저장하지 않고 해시만 보관한다.
입력 실패는 발급당 5회까지 기록하며, 5회 실패 후에는 올바른 코드도 거절하고 재전송을 안내한다.
재전송 대기는 발급 후 60초다. 만료·실패 횟수·재전송 기준은 서버가 판단하고 실패 횟수는 DB에 남긴다.
기존 링크는 전환 전 발급된 토큰에 한해서 기존 5분 만료까지 호환한다. 코드 발급 정보는 링크로 인증할 수 없다.
다른 브라우저의 기존 세션도 현재 세션 조회 시 회원 상태를 다시 읽는다.

이미 저장된 계정은 초기 메일 발송 실패와 무관하게 가입 성공으로 응답하고, 재전송으로 복구한다. SMTP 수락과
수신함 도착은 구분하며 실제 미수신 원인은 운영 로그와 수신함을 별도로 확인한다.
