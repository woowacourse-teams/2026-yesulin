## 검증 근거

- 격리 프론트 환경에서 심사·PDF 뷰어·사이드바·분석 테스트 45개 파일의 274개 테스트와 `npm run lint`, 기본 `npm run build`가 통과했다. 판정 요청 중에는 경로와 탭 이동을 보류하며, 메모 저장 실패는 현재 상세와 입력을 보호하는 것을 회귀 테스트로 확인했다.
- Chrome에서 합성 지원서 3건으로 카드 기본 화면, 상세에서만 나타나는 상단 이전·다음, 원본 렌더링, 경로의 파일명 변경과 심사함 이름 클릭 후 카드 복귀를 확인했다. 데스크톱 사이드바를 닫았을 때 필터가 본문으로 이동하지 않고 현재 상세가 유지됐다.
- 모바일 폭에서 관리 메뉴의 배역 필터로 합성 지원서를 1건으로 줄이고 상세를 열었다. 경로와 양 끝 이동 버튼, `폴더 선택`과 `PDF 추가`가 나타났으며 페이지의 가로 스크롤 폭이 뷰포트와 같았다.
- 기본 조작 이벤트의 새 `list` 값과 v2를 기존 v1과 분리했다. 조작 이벤트 속성의 파일명 미포함, 목록 표시와 자동 이동에서 조작 이벤트 미발생, 분석 동의 및 환경 제외의 회귀 테스트를 확인했다. 대시보드 스크립트 구문 검사를 통과했다.
- 앱 확인은 로컬 합성 데이터로 수행했다. 개발 서버의 업로드·판정·배포는 이 검증에 포함하지 않았다.
