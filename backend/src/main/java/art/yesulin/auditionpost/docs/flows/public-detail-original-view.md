# 공고 상세 원문 크게 보기

원문 공고는 본문 사진(대개 포스터 한 장)인 경우가 많다. PC에서는 카드 폭에 맞춰 사진이 세로로 길게 늘어나 한 화면에 들어오지 않는다.

1. 본문에 사진이 있으면 제목 아래 정보 영역에 `원문 크게 보기` 버튼을 둔다. 사진이 두 장 이상이면 장 수를 함께 보인다.
2. 버튼은 첫 사진부터, 본문 사진을 누르면 그 사진부터 전체 화면 뷰어(`ImageLightbox`)를 연다.
3. 뷰어는 사진을 화면에 맞춰 한 번에 보여 주고 2배 확대·이전/다음·Esc 닫기를 제공한다. 모바일도 같은 뷰어를 쓴다.
4. 링크로 감싼 본문 사진은 뷰어를 열지 않고 원래 링크로 이동한다.
5. 사진이 없는 글 공고에는 버튼을 두지 않는다.

사진 목록은 서버가 정리한 `bodyHtml`의 `img src`를 문서 순서대로 읽는다. API 계약·조회수·분석 이벤트는 바꾸지 않는다.
