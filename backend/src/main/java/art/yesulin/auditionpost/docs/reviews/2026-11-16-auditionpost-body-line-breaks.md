## 근거

- 2026-11-16 로컬 Node 24.16.0에서 `AuditionPostBodyEditor`와 같은 Tiptap 확장을 jsdom에 설치해 편집 동작을 재현했다. Enter 1회는 연속된 `<p>` 두 개, Enter 2회는 사이에 `<p></p>`, Shift+Enter 1·2회는 각각 `<br>`와 `<br><br>`를 직렬화했다.
- `AuditionPostForm`은 편집기 HTML을 `bodyHtml`로 전달한다. 로컬 Java에서 저장에 사용하는 `AuditionPostBodySanitizer` 소스를 Jsoup 1.23.2로 실행해 네 입력이 보존됨을 확인했다. 편집 중에는 ProseMirror가 빈 문단에 입력을 위한 `ProseMirror-trailingBreak`를 추가한다. `AuditionPostContent`가 미리보기·공개 상세에 표시하는 저장 HTML의 빈 문단에는 해당 `<br>`가 없고, `.post-body p`의 하단 여백은 `0.25em`이다. 빈 문단에 한 줄 높이가 생기지 않는다.
- `## 제목`, `**굵게**`, `- 항목`을 직접 타이핑하면 각각 제목, 굵은 글씨, 목록으로 변환됐다. 서식 없는 마크다운을 붙여넣으면 굵은 글씨는 변환됐고 제목·목록 표시는 문자로 남았다. `[링크](URL)`의 URL 부분에는 자동 링크가 걸렸고 문법 전체는 변환되지 않았다. 공개 상세는 서버가 정리한 HTML을 표시한다.
