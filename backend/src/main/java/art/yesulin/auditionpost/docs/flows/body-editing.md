# 공고 본문 작성과 미리보기

1. 관리자와 기획사 공고의 작성·수정 화면은 같은 본문 편집기를 사용한다. 서식 버튼과 `### 제목`, `**굵게**`, `- 목록` 같은 입력 단축 문법으로 글의 형식을 바꿀 수 있다.
2. 넓은 편집 영역에서는 작성과 본문 미리보기를 나란히 표시한다. 좁은 화면에서는 `작성`과 `미리보기` 버튼으로 전환하며 편집 내용은 유지한다.
3. Enter를 두 번 눌러 생긴 빈 문단은 작성 중, 저장 미리보기, 공개 상세에서 한 줄 높이를 갖는다. 이미 저장된 빈 문단에도 같은 스타일을 적용한다.
4. 편집 중 미리보기는 작성 중인 본문을 읽고 링크를 표시용으로 처리한다. 기존 본문을 편집하기 전에는 서버가 반환한 HTML을 읽는다.
5. 저장할 때 서버가 HTML과 공고에 연결된 사진을 검증한다. 본문을 고치지 않은 수정 요청에서는 서버가 기존 본문을 보존한다.
