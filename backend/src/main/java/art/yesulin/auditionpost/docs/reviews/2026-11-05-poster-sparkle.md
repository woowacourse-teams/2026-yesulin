# 글씨 카드 반짝이 애니메이션

작업 ID `2026-11-05-poster-sparkle`, 평가일 2026-11-05, 공고 v1. 프론트 화면만 바꾼다.
포스터 없이 글씨만 있는 공고·이벤트 카드(기본 포스터)의 로고 반짝이에 움직임을 넣는다. design-lab 시안 C를 사용자 의견으로 다듬었다
(작아지는 동작 제거, 긴 꽃잎 한쪽만 금빛, 대기 없이 시작, 이미지 포스터처럼 마우스 확대, 모바일 효과).

- 카드가 처음 화면에 60% 이상 들어올 때 반짝이가 크기 그대로 한 바퀴(1.1초) 돌며 오른쪽 위 긴 꽃잎 끝만 금빛이 됐다 돌아온다.
- 마우스를 올리면 한 번 더 돌고(뗄 때는 돌지 않음), 앞면이 1.03배 커진다. 터치 화면은 누르는 동안 카드가 0.98배로 작아진다.
- 움직임 줄이기 설정에서는 돌지도 크기가 바뀌지도 않는다. API·분석 이벤트는 바꾸지 않는다.
