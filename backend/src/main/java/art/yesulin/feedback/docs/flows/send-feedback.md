# 화면에서 의견 보내기

1. 공개 화면 오른쪽 아래의 "의견 보내기" 버튼을 누르면 작은 창이 열린다. 로그인하지 않아도 보낼 수 있다.
2. 종류(불편해요·오류예요·제안해요)를 고르고 내용(1~1000자)을 쓴다. 답을 받고 싶으면 연락처(100자 이내)를 적는다.
3. 화면 캡처 같은 사진을 최대 3장 붙일 수 있다. 화면이 긴 변 1600px JPEG로 줄인 뒤 보내고, 서버는 JPEG·PNG·WebP 한 장 5MB 이하만
   받아 비공개 저장소에 둔다. 개인정보는 가려 달라고 안내한다. 지금 보던 화면 경로가 자동으로 붙는다. 쿼리와 해시는 버린다. 서버는 브라우저 정보(User-Agent)를 함께 저장한다.
4. 저장이 커밋되면 슬랙 채널로 종류·보낸 사람 구분·사진 장수·화면·운영자 화면 링크·내용 일부를 보낸다. 연락처는 "남김" 여부만
   알리고, 연락처 원문과 사진은 운영자 화면 `/admin/feedback`(받은 의견)에서 확인한다. 사진은 잠깐만 열리는 주소로 보여 준다.
5. 의견 전용 웹훅이 없으면 버그 알림 채널로 보낸다. 둘 다 비어 있으면 저장과 로그만 하고, 알림 실패는 접수 결과에 영향을 주지 않는다.
   같은 접속 주소에서 10분 안에 5건을 넘기면 잠시 후 다시 보내 달라고 안내한다. 공연 상세처럼 아래 고정 버튼이 있는 화면에서는 버튼을 그 위로 올린다.
6. 보내기에 성공하면 창 안에서 감사 문구를 보이고, 실패하면 작성한 내용을 그대로 두고 다시 시도할 수 있다.

답장 기능은 아직 없다. 연락처·내용·사진의 보관 기간은 [미결정 사항](../../../../../../../../docs/pending-decisions.md)에서 정한다.
