# 공연사 일정 명단 준비

1. PDF 심사의 합격자 연락처 화면에서 대상을 선택한다. 전화·이메일은 없어도 된다.
2. 기본 화면에서는 관리할 일정을 선택한다. 새 일정은 ‘새 일정 만들기’를 눌러 제목(1~60자) 입력을 열고 생성한다. 입력창을 닫아도 작성 중인 제목과 기존 명단은 유지하고, 생성 성공 때만 새 일정으로 전환한다. 생성 성공 뒤 가져오기 실패 시 초안을 재사용한다.
3. 이름(1~30자)·선택 연락처를 확인해 등록한다. 여러 심사함의 합격자를 같은 일정에 모을 수 있다.
4. 등록한 연락처를 수정하거나 명단에서 제외한다. 원본 PDF·판정·메모·배역은 유지된다.
   원본 판정이 바뀌면 다시 조회한 명단에 확인 필요로 표시한다.

5. 명단에서 ‘날짜·시간 배정’과 ‘연락처 관리’ 보기를 전환한다. 한 번에 한 명단만 표시하며 전환해도 미저장 입력은 유지한다.
   날짜·시간 입력에서 개인별로 수정하거나 대상을 선택해 같은 날짜·시간을 일괄 적용한다.
   배정 해제도 저장 전 변경이며, 변경된 인원 수와 강조 표시를 확인한 뒤 ‘배정 저장’을 누른다.
   저장·결과 안내는 명단을 스크롤하는 동안 하단에 유지한다. 개인별 ‘저장값으로 되돌리기’와
   ‘배정 변경 전체 취소’는 배정 입력만 취소하며 연락처 입력은 유지한다.
   연락처 수정은 해당 사람의 행 안에서 열리고, 저장·취소 후 그 사람의 수정 버튼으로 초점을 돌린다.
6. 서버 저장 성공 후 저장된 시간이 갱신된다. 실패하면 입력을 보존하며 재시도한다.
   다른 화면에서 시간이 바뀌면 충돌을 안내한다. 다시 불러오기는 미저장 입력 폐기 확인 후 최신 명단을 읽는다.
   화면 이동·새 일정 생성·브라우저 이탈 때 미저장 변경 또는 진행 중 요청을 보호한다.

한국 시간 분 단위의 개인별 시작 시각을 자유롭게 정한다. 같은 시간 여러 명, 날짜 변경, 배정 해제를 허용한다.
확정, 배우 공개, 문자/이메일 발송은 후속이다.
기존 비로그인 일정의 배정·확정 경로에 연결하지 않는다. 초안은 관리 열쇠가 없고 메시지 큐를 만들지 않는다.
