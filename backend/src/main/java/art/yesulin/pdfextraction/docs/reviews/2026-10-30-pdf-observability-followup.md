## SSM 원본 조사 추가

사용자 지시로 같은 dev 인스턴스에 Session Manager로 접속하여 `/var/log/yesulin/yesulin.log`의 12:30~12:45 KST를 읽었다.
12:35~12:36 총 8개 작업 중 AI_COMPLETED 5개, AI_ATTEMPT_FAILED 3개이며 모두 INVALID_MODEL_OUTPUT/retryable=false다.
실패 시각은 12:35:33, 12:35:43, 12:36:30이다. 첫째·셋째는 AI_RESPONSE_RECEIVED 뒤라 파서의 JSON·스키마·근거 검증 거부이고,
둘째는 AI_RESPONSE_RECEIVED 전이므로 Bedrock 클라이언트의 종료 상태/응답 본문 검증 거부 범위다.
기존 단일 오류 코드로는 잘림·빈 출력·개별 필드/근거 위반을 더 구분할 수 없다. 원문·모델 응답은 추가 출력하지 않았다.
정상 5건은 저장 완료의 증거이며 내용의 정확성까지 검증한 것은 아니다.
systemd journal에서 12:31:40 정상 종료, 12:31:48 프로세스 시작, 12:32:21 앱 기동 완료를 확인했다.
해당 8건은 재시작 이후 접수된 요청이다. 서버 메모리/재부팅과 모델 품질 저하의 인과는 확인되지 않았다.
실제 dev 로컬 DEBUG 기록은 존재하고 CloudWatch 필터에서 누락된다는 점까지 확인했다. 필터 수정의 배포·수집 확인은 여전히 미실시다.
