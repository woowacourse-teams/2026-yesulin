# 커뮤니티 작업 규칙

최상위·백엔드·프론트 공통 규칙과 공통 평가 절차를 적용한다. 기능 정책은 이 폴더의 README에서 연결한 정본을 따른다.

- 공개 열람, 활성 배우의 새 글·댓글 작성, 작성물별 익명/프로필 선택과 브라우저별 좋아요를 유지한다.
- 회원 소유와 과거 쿠키 소유를 구분하고 과거 권한·번호를 자동 계정 귀속이나 재번호로 변경하지 않는다.
- 프로필 공개는 현재 공개 배우 페이지를 재사용하며 비공개·잠금·조건 미충족 시 이름·사진·링크를 노출하지 않는다.
- 생성 재시도, 소유권 거절, 삭제와 댓글 수, 최초 신고 알림 기록을 평가한다.
- dev 통합은 기존 인증·분석·메뉴·설정을 보존하고 DB 변경 순서를 검사한다.
- 독립 평가는 기본 1회이며 범위 밖 실제 Slack 연결·운영 부하 검증은 통과로 간주하지 않는다.
