## 검증 근거

- T1·T2: H2(MySQL 모드)와 Flyway를 쓰는 CommunityTopicsTest에서 기본값, 주제 저장·수정, 이전 클라이언트의 수정, 동일 요청 재시도, 주제별 다음 커서와 비회원 권한을 검증했다. MSW와 로그인 배우 폼에서도 선택·초안 복원·제출을 확인했다.
- T3·T4: 같은 서비스 테스트로 7일 경계 양끝, 미래·기간 밖, 2점/3점, 삭제, 동점 정렬, 최대 5개를 확인했다. 쿼리는 글 번호·제목만 투영한다. MSW 공개 응답의 필드도 검증했다.
- T5·T6: 3100번 MSW 및 합성 목록 응답으로 Chrome에서 1440·1100·860·375px를 확인했다. 소개 영역의 기존 구성, 가운데 필터, 별 아바타, 인기 글→마감 임박 공고 순서, 375px 칩 스크롤, 페이지 가로 넘침 없음, 주소 재조회·뒤로가기·로그인 복귀 주소와 인기 조회 실패 시 피드·공고 유지 확인. 분석 이벤트 속성에 주제를 넣지 않았다.
- T7: 기준 dev의 최신 마이그레이션 다음에 단일 ADD COLUMN과 인덱스를 적용한다. 순서와 이전 릴리스 호환 스크립트 통과. 격리된 MySQL 9.7.0에서 기존 글을 넣은 후 마이그레이션하여 FREE를 확인했고, MySQL 전용 임시 데이터베이스에서도 같은 서비스 테스트 4개가 통과했다.
- 커뮤니티 백엔드 테스트 42개, checkstyleMain/checkstyleTest 통과. 로컬 설정 파일·합성 데이터·임시 MySQL과 브라우저 검증 파일은 변경 목록에서 제외했다.
- 체크아웃에 지정된 launch.json이 없어 같은 MSW 환경 변수를 사용해 3100번 포트로 실행했다. 실제 소셜 로그인과 dev 로그인 세션에서의 작성·수정은 병합 후 dev에서 확인 필요.
