## 사용자 검토 후 추가 변경

- 화면·메뉴 이름을 `익명게시판`으로 바꿨다. 주소 `/community`와 코드 이름은 유지한다.
- 작성·댓글 화면의 브라우저 소유 안내와 익명 번호 유지 범위 안내를 제거했다(요구사항 C06에 사용자 결정 기록).
- "댓글 처음부터 보기"를 댓글 링크로 중간부터 열었을 때만 보이는 `··· 이전 댓글` 버튼으로 바꿨다.
- 데스크톱에서 내용이 짧을 때 푸터가 화면 중간으로 올라오지 않도록 본문이 남은 높이를 채운다.
- 검증: 관련 10파일 42개 테스트·tsc·lint 통과. 1280×900 브라우저에서 빈 목록의 푸터 위치, `#comment-3` 진입 후 이전 댓글 불러오기와 버튼 사라짐을 확인했다.
- 사용자 확인 후: 댓글 Enter 전송(Shift+Enter 줄바꿈, 한글 조합 중 무시), 댓글·작성 화면의 세로선 제거(목록의 댓글 있음 표시만 유지),
  익명게시판 전용 간결 푸터(저작권·정책·문의·분석 설정)로 교체. 브라우저에서 기존 댓글 2개가 있는 글에 Enter로 댓글을 달아 3개 모두 보이는 것을 확인했다.
