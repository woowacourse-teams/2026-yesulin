### iPhone 13 Pro 연결 후 준비 확인

- 2026-11-17, iOS 27.2.1의 Safari에서 현재 프론트 수정본의 글쓰기 경로를 열고 입력칸 렌더링과 초기 포커스를 확인했다. 임시 로컬 서버는 목 배우 세션과 커뮤니티 목 API를 사용했다.
- iPhone 미러링에서 제목·본문에 초점을 두면 Safari의 이동 화살표와 완료 버튼이 보였고 iPhone 화면 키보드는 나타나지 않았다. 테스트용 제목과 본문을 채운 상태에서 직접 조작으로 넘겼다.
- 화면 키보드 입력과 글·댓글 저장 요청을 관측하기 전까지 iPhone D01~D03은 UNVERIFIED다. Android는 이번 연결 확인의 범위 밖이다. 독립 평가 1회에서 실기기 판정 기준과 기존 링크를 확인했으며 신규 확정 문제는 없다.

### iPhone 새 글 키 입력 확인

- 2026-11-17, iPhone 13 Pro의 Safari에서 사용자가 화면 키보드의 ‘다음’과 줄바꿈 키를 직접 눌렀다. 제목·본문을 모두 채운 상태에서 제목에서 본문으로 초점이 이동했고, 본문에서 브라우저의 `insertLineBreak`가 기록됐다. 줄바꿈 중 글 등록 요청은 없었다.
- 사용자가 ‘올리기’를 눌렀다고 보고했지만 해당 iPhone의 등록 요청이나 저장된 글은 초기 테스트 서버에서 확인하지 못했다. 별도 데스크톱 대조에서 등록 201 뒤 상세 조회 404를 재현했다. 목 데이터 저장을 별도 로컬 프로세스로 옮긴 뒤 데스크톱에서 다시 등록하고 상세의 빈 줄을 확인했다. 초기 서버의 문제와 iPhone의 요청 누락은 별개로 관찰했다.
- 새 글 제목 이동과 본문 줄바꿈은 실기기에서 일부 확인했다. 등록과 글 수정, 댓글·대댓글 작성·수정, 제목 한글 조합 확정까지 확인하려면 보완한 서버에서 추가로 관찰해야 한다. 이 회차 독립 평가 1회에서 근거와 판정 범위를 검토했다. D01~D03 전체는 UNVERIFIED이며 제품 결함을 새로 확정하지 않았다.
