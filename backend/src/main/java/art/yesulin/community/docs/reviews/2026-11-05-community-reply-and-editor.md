# 대댓글 입력칸 위치·글쓰기 칸·홈 띄어쓰기 수정

작업 ID `2026-11-05-community-reply-and-editor`, 평가일 2026-11-05, 커뮤니티 v1. 프론트만 바꾼다.

- 대댓글을 누르면 입력칸이 맨 아래가 아니라 그 댓글 묶음 바로 아래에 열린다. 원댓글이 아직 불러와지지 않았거나 대상이 대댓글이면 맨 아래 입력칸을 쓴다.
- 글쓰기 화면의 제목·본문 칸이 좁은 오른쪽 단으로 몰리던 문제를 고친다. #535에서 수다방 글쓰기 유도 카드에 붙인 `.community-compose`가
  기존 글쓰기 폼과 같은 이름이라 가로 배치가 폼에 걸렸다. 유도 카드 이름을 `.community-compose-prompt`로 바꿨다.
- 홈 안내 배너가 모바일에서 줄바꿈을 숨길 때 "소식가장", "이번 주무료"처럼 붙던 문제를 줄바꿈 앞 공백으로 고친다.
