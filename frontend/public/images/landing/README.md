# 랜딩 이미지와 글꼴

- `guide-*.png`: 2026-10-29 예술in 공개 서비스의 이용 안내용 화면 캡처
  오디션 목록 `/auditions`, 무료 공연 상세의 회차 선택, 공연사 서비스 안내 `/producer-service`다
  공연사 이미지는 공개 소개 화면이며 로그인 후 운영 도구의 실사용 캡처가 아니다
  표시된 공고·공연과 모집 상태는 캡처 시점의 예시이며 실제 이용 시 연결된 화면을 확인한다

- `audition-room.webp`: 사용자 제공 팀 사진을 참고한 극장 연출 이미지
  실제 오디션 현장 사진이 아니다
  처음 생성한 1672×941 WebP를 사용하며 좌석과 얼굴을 재편집하지 않는다
  세 번째 노트북의 클릭 지점은 정규좌표 (0.7808014354, 0.6424017003)다
- `poster-*.jpg`: 기존 디자인 작업에 보관된 실제 공개 공고 이미지의 사본
  원본 파일은 `../design-lab/post-{id}.jpg`이며 공고는 `/posts/{id}`로 연결한다
  현재 모집 상태를 의미하지 않는다
- 추가 포스터 12개는 예술in 공개 API의 `thumbnailUrl`에서 원본을 보관했다
  공개 API `/api/v1/public/audition-posts`의 공고 ID와 연결하며 총 18개다
- `MaruBuri-Regular.woff2`: 네이버 마루부리 Regular
  공식 출처: https://hangeul.pstatic.net/hangeul_static/css/maru-buri.css
  SIL OFL 1.1 전문과 저작권은 `MaruBuri-LICENSE.txt`에 보관한다

## 장면 생성 프롬프트

배우가 어두운 소극장 무대 위에서 객석을 바라보는 시점
정면 객석은 검고 흐릿하며 따뜻한 조명이 한두 개 보인다
하단 20%에 나무 무대 바닥이 있고 중앙부터 왼쪽 70%는 텍스트가 놓일 어두운 여백이다
극우측 아래에는 첨부 사진을 참고한 젊은 한국인 남성 다섯 명이 긴 테이블 뒤에 앉아 맥북 다섯 대를 사용한다
얼굴은 화면 불빛에 희미하게만 비친다
실사 영화 스틸 분위기, 흑갈색과 따뜻한 호박색, 약한 필름 질감
별도 커튼은 넣지 않고 텍스트와 워터마크도 넣지 않는다
