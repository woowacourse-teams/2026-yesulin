# 미구현 사항

현재 정본과 API에는 아래 항목을 구현된 것처럼 기록하지 않는다. 구현 작업을 시작하거나 완료 상태를 변경할 때만 이 문서를 읽는다.

## 제품·계정

- 기획사/제작사의 여러 직원 계정, 초대, 세부 권한
- 기획사/제작사 계정 이메일 변경과 휴대폰 확인
- 회원 탈퇴와 개인정보 권리 요청 처리 API
- 배우 계정 자체 조회·수정 API (`/applicants/me`)
- 전용 프로필 prefill API

## 공고·지원·심사

- OTR 지원서의 목록·상세와 심사 연결, 마감에 따른 영속 상태 전환
- 추천 공고 목록 API
- 공고 전용 대표 이미지·상세 이미지·연습 장소·지원 안내
- 서버 Draft와 여러 기기 동기화
- 만 14세 미만 제출 차단
- 차수별 심사 마감과 `ABSENT` 상태: 현재 MVP 정책에서는 제외
- 배우에게 심사 결과를 공개하거나 알리는 API

## 오디션 일정표

- 일정표 문자의 문자 업체 자동 발송. 현재는 운영자가 대기열에서 직접 보내고 완료로 표시한다.
- 로그인 없는 일정표 생성의 남용 방지(생성 빈도 제한 등). 자동 발송으로 바꾸기 전에 필요하다.
- 일정표·배우 연락처·문자 기록의 삭제와 자동 파기, 관리 링크 재발급
- 기존 공고·OTR 배역의 합격자 불러오기와 기획사 계정 연결
- 배우의 직접 변경을 기획사에게 알리는 기능(현재 보드 표시만 한다)

## 파일·운영

- magic byte 검사, 이미지 디코딩, 악성 파일 검사, EXIF 제거
- 미참조 임시 업로드와 원본·정제본 자동 정리
- 지원서·심사·파일의 보관기간 계산과 자동 파기
- 지원서·파일 접근과 다운로드·출력 추적, 권리 요청 대장

## 공개 정책·출시

- `/terms`, `/privacy` 공개 화면과 전역 링크
- 동의 화면에 표시한 목적·제공 항목·보유기간의 제출 시점 스냅샷
- 기획사 가입 약관 동의의 버전·시각 저장
- 수탁자, 국외 이전, 보유기간, 파기 절차의 정식 출시 계약
