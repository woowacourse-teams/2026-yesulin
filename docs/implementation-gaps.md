# 미구현 사항

현재 정본과 API에는 아래 항목을 구현된 것처럼 기록하지 않는다. 구현 작업을 시작하거나 완료 상태를 변경할 때만 이 문서를 읽는다.

## 제품·계정

- 기획사/제작사의 여러 직원 계정, 초대, 세부 권한
- 기획사 비밀번호 재설정과 이메일·휴대폰 확인
- 회원 탈퇴와 개인정보 권리 요청 처리 API
- 배우 계정 자체 조회·수정 API (`/applicants/me`)
- 전용 프로필 prefill API

## 공고·지원·심사

- 추천 공고 목록 API
- 공연 삭제 API
- 공고 전용 대표 이미지·상세 이미지·연습 장소·지원 안내
- 서버 Draft와 여러 기기 동기화
- 만 14세 미만 제출 차단
- 지원서 제출·내 지원서 Controller의 서버 수준 `APPLICANT` 역할 제한
- 차수별 심사 마감과 `ABSENT` 상태: 현재 MVP 정책에서는 제외
- 배우에게 심사 결과를 공개하거나 알리는 API

## 파일·운영

- magic byte 검사, 이미지 디코딩, 악성 파일 검사, EXIF 제거
- 미참조 임시 업로드와 원본·정제본 자동 정리
- 지원서·심사·파일의 보관기간 계산과 자동 파기
- 감사 로그, 다운로드·출력 추적, 권리 요청 대장

## 공개 정책·출시

- `/terms`, `/privacy` 공개 화면과 전역 링크
- 실제 제공받는 기획사명과 정책 버전을 사용하는 동의 문서
- 기획사 가입 약관 동의의 버전·시각 저장
- 수탁자, 국외 이전, 보유기간, 파기 절차의 정식 출시 계약
