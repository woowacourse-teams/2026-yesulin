# 변경 경로별 CI 평가

- 작업 ID `2026-11-18-common-selective-ci`, 평가표 v1
- 범위는 GitHub CI의 변경 분류, 검사 선택, 시간 비교다.

| 항목 | 단계와 실패 조건 | 기대 결과 | 검증 방법 | 필수 |
| --- | --- | --- | --- | --- |
| C01 | 변경 분류에서 폴더 밖 입력 또는 무관한 경로를 잘못 분류한다 | 필요한 검사만 선택한다 | 규칙 사례와 현재 추적 파일 검사 | 예 |
| C02 | 파일 이동·삭제, 범위 확인 실패 또는 미분류 파일을 놓친다 | 양쪽 경로를 분류하고 오류 시 검사를 실패시킨다 | 임시 Git 저장소와 오류 사례 | 예 |
| C03 | 기존 필수 체크가 빠지거나 동일 브랜치의 push 검사 범위를 취소로 누락한다 | 기존 이름을 보고하고 해당 push를 검사한다 | 워크플로 검사와 GitHub 실행 | 예 |
| C04 | 비교 시점, 코드 버전 또는 실행 시간이 뒤섞인다 | 실행·시도·SHA와 원래 시각을 남기고 같은 범위를 비교한다 | 실제 기존 실행 기록과 측정 도구 검사 | 예 |
| C05 | 배포 경로나 자격 증명을 변경한다 | 기존 권한 범위 안에서 CI만 변경한다 | 변경 범위 확인 | 예 |
| C06 | GitHub에서 실행할 때 체크 보고나 측정이 다르게 동작한다 | 동일 ref에서 실행 결과와 메타데이터가 일치한다 | 실제 GitHub 러너에서 일반 실행과 수동 비교 실행 | 예 |
