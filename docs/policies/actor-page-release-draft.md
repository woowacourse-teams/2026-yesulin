# 배우 페이지·PDF로 채우기 출시 문구 초안

이 문서는 현재 코드 동작을 바탕으로 만든 검토용 개정안이다. 공개 정책의 확정본·시행일·법적 근거를 대신하지 않는다.
확정할 사항은 [미결정 사항](../pending-decisions.md)에 두고, 공개 문서와 실제 화면 반영은 확정 후 진행한다.

## 배우 페이지 공개 화면 문구 제안

> 배우 페이지를 공개하면 이름, 성별, 출생연도·나이, 입력한 키·몸무게와 공개로 설정한 사진·영상·항목을 누구나 볼 수 있습니다.
> 배우 목록에 표시되며 검색엔진에 수집·노출될 수 있습니다. 연락처, 전체 생년월일, 거주지, 병역 정보는 공개 페이지에 표시하지 않습니다.
> 언제든 배우 페이지를 비공개로 바꿀 수 있습니다. 이미 외부에서 저장한 사본이나 검색 결과는 즉시 사라지지 않을 수 있습니다.

체크박스 제안: `위 내용을 확인하고 배우 페이지 공개에 동의합니다. (공개 시 필수)`

공개하지 않아도 프로필을 저장·편집할 수 있다. 재공개할 때마다 체크를 다시 받고 서버는 동의 버전·회원·페이지·시각을 기록한다.
현재 구현 버전은 `actor-page-publish-v1.0`이다. 위 문구 확정 시 기존 동의와 의미가 달라지는지 검토하고,
필요하면 서버·프론트·목의 문서 버전을 함께 올린다. 이 초안 작성만으로 기존 버전을 바꾸지 않는다.

| 배우 페이지 | 아이디, 이름, 성별, 출생연도·나이, 입력한 키·몸무게, 공개로 설정한 사진·영상·선택 항목을 비로그인 이용자·검색엔진에 공개. 전화·이메일은 운영자 연결 문의에만 사용 | 공개 처리의 고지·동의 구성, 운영자 연락처 처리 안내, 동의 이력 보유기간 |

| PDF로 채우기 | 배우가 선택한 PDF, 추출 본문·이미지, 이름·생년월일·나이·키·학력·경력 제안과 원문 근거를 비공개 처리. 자동 프로필 저장은 하지 않음 | 실제 AI 제공자·계약·전송 국가·지역·보관·학습 이용 여부와 고지 방식 |
| PDF 정리 | 결과 삭제 요청 시 원본·추출 본문·이미지·payload 삭제. 결과 생성 후 24시간 경과 시 30분 주기 정리. 미완료 작업은 생성 시각 기준 | 실제 S3·DB 삭제, 장애 시 재시도·처리 지연 안내, 백업·로그 범위 |
| 사진 후보 저장 | 배우가 선택한 후보는 별도 비공개 배우 사진 파일로 복사. PDF 결과 삭제 뒤에도 보관함에 남음 | 기존 보관함 파일의 삭제·보유 정책과 연결 |

외부 AI는 설정에 따라 사용 여부와 제공자가 달라진다. 지원 가능한 제공자를 모두 실제 수탁자처럼 쓰지 않고,
출시 환경에서 선택한 제공자의 조건을 확인한 뒤 해당 사실만 처리방침에 반영한다.

## 이용약관에 추가할 문구 제안

> 배우는 본인이 공개 권한을 가진 자료로 배우 페이지를 만들고 항목·사진·영상의 공개 범위를 선택할 수 있습니다.
> 공개한 페이지는 누구나 볼 수 있고 검색엔진에 노출될 수 있습니다. 배우는 언제든 비공개로 전환할 수 있습니다.
> 공개 범위를 바꾸더라도 이용자·검색엔진이 이미 별도로 저장한 자료의 회수까지 보장되지는 않습니다.

> PDF로 채우기는 배우가 선택한 PDF에서 정보를 읽어 입력을 돕는 기능입니다. 추출·정리 결과에는 오류나 누락이 있을 수 있으므로
> 원문 근거를 확인하고 수정한 뒤 직접 프로필을 저장해야 합니다. 사진 후보를 보관함에 넣는 선택은 즉시 저장됩니다.
> 결과를 지우면 임시 PDF와 추출 자료를 삭제하고, 남겨 둔 결과는 생성 후 24시간이 지나면 정기적으로 정리합니다.
> 보관함에 별도로 저장한 사진은 PDF 결과와 구분해 관리합니다.
