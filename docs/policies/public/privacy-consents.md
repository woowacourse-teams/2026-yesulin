# 예술in 개인정보 동의문

> 문서 버전: 1.0<br>
> 시행일: 2026-09-07

개인정보처리자는 예술in 프로젝트팀(대표자 강민준)이며, 개인정보 문의는 contact@yesulin.art로 접수합니다.

계정·프로필 기능에 필요한 정보는 서비스 이용계약의 체결·이행을 위해 처리하고 [개인정보 처리방침](./privacy-policy.md)에 공개합니다. 아래에서는 특정 공고의 지원서 수집·이용과 기획사/제작사 제3자 제공을 각각 동의받습니다.

## 1. 공고 지원서 수집·이용 동의 — 필수

제출 화면에는 현재 공고가 실제로 요구하는 항목만 표시합니다.

| 고지 사항 | 내용 |
| --- | --- |
| 문서 버전 | `submission-collection-v1.0` |
| 목적 | `{{기획사/제작사명}}`의 `{{공고명}}` 지원 접수, 배우 식별, 중복 지원·연령 확인, 심사 관리, 문의 처리와 배우의 지원 내역 제공 |
| 수집 항목 | `{{해당 공고가 선택한 이름·키·몸무게·생년월일·성별·연락처·이메일·시·군·구 수준 거주지 중 실제 항목}}`, `{{실제 추가 정보}}`, 사진 최대 3장, 영상 링크 최대 3개, `{{공고별 질문과 답변}}`, 선택 배역·배역명, 모집 마감일 기준 만 나이, 제출 시각과 동의 이력 |
| 보유·이용기간 | 배우가 제출 내역을 확인할 수 있도록 지원 내역 삭제 또는 회원 탈퇴 시까지. 삭제된 운영 데이터의 백업 사본은 일반 이용이 차단된 상태로 최대 90일 안에 순환 삭제 |
| 거부권과 불이익 | 동의를 거부할 수 있지만 지원 접수·심사에 필요한 정보이므로 해당 공고에 지원할 수 없습니다. 공고에서 선택으로 표시한 항목은 제공하지 않아도 지원할 수 있습니다. |

`[ ] 위 개인정보 수집·이용에 동의합니다. (필수)`

## 2. 기획사/제작사 제3자 제공 동의 — 필수

| 고지 사항 | 내용 |
| --- | --- |
| 문서 버전 | `submission-third-party-v1.0` |
| 제공받는 자 | `{{기획사/제작사의 정확한 운영 주체 명칭}}` |
| 제공 목적 | `{{공고명}}` 오디션 지원 접수·심사·일정·결과 연락과 동일 공연의 결원·대체 캐스팅 연락 |
| 제공 항목 | `{{배우가 해당 공고에 실제 제출하는 항목}}` |
| 보유·이용기간 | 전형 종료 후 30일. 기획사/제작사가 전형을 종료하지 않으면 모집 마감 후 120일. 다른 법령상 보존 의무가 있으면 해당 정보만 분리 보관 |
| 거부권과 불이익 | 동의를 거부할 수 있지만 지원서를 해당 기획사/제작사에 전달할 수 없어 이 공고에 지원할 수 없습니다. |

`[ ] 위 개인정보 제3자 제공에 동의합니다. (필수)`

이 동의는 현재 선택한 기획사/제작사와 공고에만 적용됩니다. 다른 기획사/제작사의 공고에 지원할 때에는 다시 고지하고 동의받습니다. 다운로드·출력본에도 같은 보유기간이 적용됩니다.

## 3. 지원서 정보를 프로필에 저장 — 선택 기능

`[ ] 이번 지원서 정보를 프로필에 저장`

이 선택은 개인정보 동의가 아니라 이용자가 요청하는 프로필 기능입니다. 선택하면 이번 지원서에 입력한 기본·추가 정보를 프로필에 옮겨 다음 지원서에 자동으로 채웁니다.

- 사진, 영상 링크, 공고별 추가 질문 답변은 옮기지 않습니다.
- 선택하지 않아도 지원할 수 있습니다.
- 프로필에 저장된 항목은 프로필 화면에서 수정·삭제할 수 있습니다.
- 프로필 저장이 실패해도 지원서 제출 성공에는 영향을 주지 않습니다.

## 화면·서버 구현 기준

- 제1절과 제2절은 각각 필수 체크박스로 표시하고 서버에도 동의 이력을 별도로 저장한다.
- `필수 항목 모두 동의`는 두 체크박스를 함께 변경하는 편의 기능이며 단일 동의 기록을 만들지 않는다.
- 이용약관 동의와 제1·2절의 동의를 하나의 `전체 동의` 값으로만 저장하지 않는다.
- 동의 유형, 동의 주체·지원서 ID, 문서 버전, 목적·항목·제공받는 자·보유기간의 표시 스냅샷, 공고 ID와 동의 시각을 저장한다.
- 제공받는 자, 항목, 목적 또는 보유기간이 실질적으로 바뀌면 새 동의를 받는다.
- 로컬 작성 중 지원서를 복원해도 동의 체크 상태와 제3절의 프로필 저장 선택은 복원하지 않는다.
- 새로 고른 사진은 최종 제출 시 서버에 올리고, 지원서와 연결되지 않은 파일은 24시간 이내 삭제한다.
- 최종 제출 시 서버에서 모집 중인지와 만 14세 이상인지를 다시 확인한다.
