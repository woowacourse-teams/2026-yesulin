# 예술IN 개인정보 동의문

> 상태: 실제 서비스 출시 전 초안<br>
> 문서 버전: 1.3-draft<br>
> 최종 수정일: 2026-08-21

개인정보처리자는 예술IN 프로젝트팀(대표자 강민준)이며, 개인정보 문의는 contact@yesulin.art로 접수합니다.

계정 생성·로그인에 꼭 필요한 정보는 서비스 이용계약의 체결·이행을 위해 처리하고 [개인정보 처리방침](./privacy-policy.md)에 공개합니다. 아래 문서는 동의가 처리 근거인 항목만 다룹니다.

## 1. 선택 프로필 저장 — 선택

| 고지 사항 | 내용 |
| --- | --- |
| 목적 | 다음 지원서 자동 채움과 배우 프로필 관리 |
| 항목 | 이용자가 저장에 동의한 기본 정보 8개와 학력·경력·링크·국적·자기소개·특기·취미·군필 여부 등 추가 정보. 공고별 커스텀 답변, 제출 사진과 영상 링크는 포함하지 않음 |
| 보유·이용기간 | 각 항목 삭제, 동의 철회 또는 회원 탈퇴 시까지 |
| 거부권과 불이익 | 동의를 거부하거나 철회해도 계정 이용과 지원은 가능합니다. 다만 자동 채움이 제공되지 않거나 지원할 때 다시 입력해야 할 수 있습니다. |

프로필 데이터의 계속 보관 동의와 이번 지원서 값의 프로필 갱신 선택은 구분합니다. 기본 정보 8개가 모두
채워지지 않아도 입력한 값만 저장할 수 있습니다. 지원서에서 값을 수정해도 자동 변경하지 않으며, 유효한
프로필 보관 동의가 있고 제출 화면에서 별도로 갱신을 선택한 경우에만 기본·추가 정보를 프로필에 반영합니다.

`[ ] 입력한 기본·추가 정보를 프로필에 보관하고 다음 지원에 재사용하는 데 동의합니다. (선택)`

## 2. 공고 지원서 수집·이용 — 필수

| 고지 사항 | 내용 |
| --- | --- |
| 목적 | `[기획사/제작사명]`의 `[공고명]` 지원 접수, 배우 식별, 중복 지원 방지, 심사 관리와 문의 처리 |
| 항목 | 기본: `[해당 공고에서 선택한 이름, 키, 몸무게, 생년월일, 성별, 연락처, 이메일, 시·군·구 수준 거주지]`. 추가: `[해당 공고에서 선택한 실제 추가 정보]`, 공고가 유형별 설명과 장수를 지정한 사진 최대 10장, 영상 링크 최대 5개, `[커스텀 질문 답변]`, 선택한 배역과 배역명, 모집 마감일 기준 만 나이, 제출 시각과 동의 이력 |
| 보유·이용기간 | 정상 종료: 모든 배역·차수의 전형 종료일부터 90일까지. 미마감: 모집 마감일부터 120일까지. 운영 데이터 삭제 후 백업 사본은 일반 이용이 차단된 상태로 최대 90일 안에 순환 삭제. 그 전에 정당한 삭제·처리정지 요구가 처리되면 해당 조치에 따름 |
| 거부권과 불이익 | 동의를 거부할 수 있으나 지원 접수·심사에 필요한 정보이므로 해당 공고에 지원할 수 없습니다. 선택 항목은 제공하지 않아도 지원할 수 있습니다. |

## 3. 기획사/제작사 제3자 제공 — 필수

기획사/제작사가 독립적으로 배우를 심사·연락하고 반출자료를 관리하는 개인정보 보호법상 제3자라는 전제로 작성한 초안입니다. 실제 권한·약관·운영이 이 전제와 달라지면 전문가 검토를 거쳐 문서와 동의 구조를 다시 설계합니다.

| 고지 사항 | 내용 |
| --- | --- |
| 제공받는 자 | `[기획사/제작사의 정확한 운영 주체 명칭]` |
| 제공 목적 | `[공고명]` 오디션 지원 접수·심사·일정·결과 연락과 동일 공연의 결원·대체 캐스팅 연락 |
| 제공 항목 | `[배우가 해당 공고에 실제 제출하는 항목 자동 표시]` |
| 보유·이용기간 | 전형 종료 후 30일까지. 다른 법령상 보존 의무가 있으면 해당 정보만 분리 보관 |
| 거부권과 불이익 | 동의를 거부할 수 있으나 지원서를 해당 기획사/제작사에 전달할 수 없어 이 공고에 지원할 수 없습니다. |

`[ ] 위 개인정보 제3자 제공에 동의합니다. (필수)`

이 동의는 현재 선택한 기획사/제작사와 공고에만 적용됩니다. 다른 기획사/제작사에 지원할 때에는 다시 고지하고 동의받습니다. 기획사/제작사가 자료를 다운로드·출력한 경우에도 전형 종료 후 30일까지 파기해야 합니다.

## 구현 기준

- 제2절과 제3절은 같은 문서·화면에 표시할 수 있지만 각각 필수 체크박스로 받고 동의 기록도 각각 생성한다.
- 상단 `필수 항목 모두 동의`는 제2절과 제3절 체크박스를 함께 변경하는 편의 기능으로만 제공하고 별도
  동의 유형이나 단일 동의 값으로 저장하지 않는다.
- 이용약관 동의와 위 동의를 하나의 `전체 동의` 값으로만 저장하지 않는다.
- 처리방침은 동의 대상이 아니라 항상 확인할 수 있는 링크로 제공한다.
- 동의 유형, 주체·지원서 ID, 문안 버전, 표시한 목적·항목·기획사/제작사·기간, 공고 ID와 동의 시각을 저장한다.
- 기획사/제작사나 제공 항목·기간이 바뀌면 새 동의를 받는다.
- 프로필 보관 동의와 이번 지원서 값의 프로필 갱신 선택은 서로 분리하고 지원서 제출 동의와도 분리한다.
  공고에서 선택한 기본 정보는 필수이고 선택한 추가 정보는 nullable이다.
- 커스텀 답변은 재사용 프로필에 저장하지 않는다.
- 제출 사진과 영상 링크는 이번 지원서 값의 프로필 갱신 범위에 포함하지 않는다.
- 지원서 작성은 로그인 전에 가능하지만 최종 제출은 소셜 로그인 완료 뒤에만 허용한다. 첫 소셜 로그인 시 배우 계정을 자동 생성한다.
- 인증 전 작성 내용과 사진은 현재 브라우저 IndexedDB에만 저장하며 서버 Draft·임시 파일로 전송하지 않는다.
- Draft를 복원할 때 필수 동의와 이번 지원서의 프로필 갱신 선택은 복원하지 않고 다시 받는다.
- 소셜 로그인이 최종 제출 과정에서 완료되면 로컬 Draft의 최종 검토 화면으로 복귀한다.
- 제출 버튼을 누른 시점의 서버 UTC를 기준으로 모집 중인지 다시 확인하고, 생년월일로 만 14세 미만 제출을 차단한다.
- 사진은 파일당 20MB 이하 PNG·JPEG·WebP만 받고 Backend에서 실제 형식을 확인하고 EXIF 위치정보를 제거한다.
- 제출 지원서는 프로필 정보·마감일 기준 만 나이·사진·답변·배역명·파일 참조의 제출 시점 스냅샷으로 보관하며 이후 프로필 수정이나 개인 사진 Soft Delete로 변경하지 않는다.
- Draft와 제출 지원서의 사진은 개인 사진 보관함과 독립적으로 유지한다.
- 일반 지원 철회 기능은 제공하지 않지만 개인정보 삭제·처리정지·동의 철회 요구 경로는 유지한다.
- 제출 완료 후 지원서 내용과 선택 배역을 변경하는 일반 수정 기능은 제공하지 않는다. 개인정보 정정 요구는 별도 권리 행사 절차로 판단한다.
- 기획사/제작사의 법적 지위가 수탁자로 판단되면 제3절을 그대로 사용하지 않고 위탁 계약과 처리방침 구조를 다시 설계한다.

만 14세 미만 계정 생성 허용은 법정대리인 동의·확인과 계정 단계의 개인정보 처리 근거에 대한 전문가
검토를 마치기 전에는 실제 개인정보를 처리하는 서비스에 적용하지 않는다.
