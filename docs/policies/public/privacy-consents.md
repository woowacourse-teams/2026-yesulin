# 예술IN 개인정보 동의문

> 문서 버전: 0.7-draft<br>
> 최종 수정일: 2026-08-11

개인정보처리자는 예술IN 프로젝트팀(대표자 강민준)이며, 개인정보 문의는 contact@yesulin.art로 접수합니다.

계정 생성·로그인에 꼭 필요한 정보는 서비스 이용계약의 체결·이행을 위해 처리하고 [개인정보 처리방침](./privacy-policy.md)에 공개합니다. 아래 문서는 동의가 처리 근거인 항목만 다룹니다.

| 고지 사항 | 내용 |
| --- | --- |
| 목적 | `[공연사명]`의 `[공고명]` 지원 접수, 지원자 식별, 중복 지원 방지, 심사 관리와 문의 처리 |

| 거부권과 불이익 | 동의를 거부할 수 있으나 지원 접수·심사에 필요한 정보이므로 해당 공고에 지원할 수 없습니다. 선택 항목은 제공하지 않아도 지원할 수 있습니다. |

## 3. 공연사 제3자 제공 — 필수

공연사가 독립적으로 지원자를 심사·연락하고 반출자료를 관리하는 개인정보 보호법상 제3자라는 전제로 작성한 초안입니다. 실제 권한·약관·운영이 이 전제와 달라지면 전문가 검토를 거쳐 문서와 동의 구조를 다시 설계합니다.

| 고지 사항 | 내용 |
| --- | --- |
| 제공받는 자 | `[공연사의 정확한 운영 주체 명칭]` |
| 제공 목적 | `[공고명]` 오디션 지원 접수·심사·일정·결과 연락과 동일 공연의 결원·대체 캐스팅 연락 |
| 제공 항목 | `[지원자가 해당 공고에 실제 제출하는 항목 자동 표시]` |
| 보유·이용기간 | 전형 종료 후 30일까지. 다른 법령상 보존 의무가 있으면 해당 정보만 분리 보관 |
| 거부권과 불이익 | 동의를 거부할 수 있으나 지원서를 해당 공연사에 전달할 수 없어 이 공고에 지원할 수 없습니다. |

`[ ] 위 개인정보 제3자 제공에 동의합니다. (필수)`

이 동의는 현재 선택한 공연사와 공고에만 적용됩니다. 다른 공연사에 지원할 때에는 다시 고지하고 동의받습니다. 공연사가 자료를 다운로드·출력한 경우에도 전형 종료 후 30일까지 파기해야 합니다.

## 구현 기준

- 제2절과 제3절은 같은 문서·화면에 표시해도 체크박스와 동의 기록을 각각 생성한다.
- 이용약관 동의와 위 동의를 하나의 `전체 동의` 값으로만 저장하지 않는다.
- 처리방침은 동의 대상이 아니라 항상 확인할 수 있는 링크로 제공한다.
- 동의 유형, 주체·지원서 ID, 문안 버전, 표시한 목적·항목·공연사·기간, 공고 ID와 동의 시각을 저장한다.
- 공연사나 제공 항목·기간이 바뀌면 새 동의를 받는다.
- 프로필 저장 동의는 지원서 제출 동의와 분리한다. 지원서의 기본 정보 8개는 필수이고 공연사가 선택하는 추가 정보는 nullable이다.
- 커스텀 답변은 재사용 프로필에 저장하지 않는다.
- 지원서 작성은 로그인 전에 가능하지만 최종 제출은 로그인 또는 회원가입 완료 뒤에만 허용한다.
- 일반 지원 철회 기능은 제공하지 않지만 개인정보 삭제·처리정지·동의 철회 요구 경로는 유지한다.
- 제출 완료 후 지원서 내용과 선택 배역을 변경하는 일반 수정 기능은 제공하지 않는다. 개인정보 정정 요구는 별도 권리 행사 절차로 판단한다.
- 공연사의 법적 지위가 수탁자로 판단되면 제3절을 그대로 사용하지 않고 위탁 계약과 처리방침 구조를 다시 설계한다.
