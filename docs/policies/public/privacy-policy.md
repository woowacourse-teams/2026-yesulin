예술IN 프로젝트팀(대표자 강민준, 이하 “운영팀”)은 예술IN 서비스를 운영하며, 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고 권리를 보장하기 위해 이 개인정보 처리방침을 수립·공개합니다.

이 방침은 실제 수탁자, 처리 국가와 시스템 구현을 확인한 후 시행합니다. 시행 전까지 예술IN은 더미 데이터 기반 데모로만 운영합니다.

제출된 지원서는 제출 시점의 프로필 정보·마감일 기준 만 나이·사진·커스텀 답변·선택 배역명과 파일 참조를 별도 스냅샷으로 보관합니다. 이용자가 이후 프로필을 수정하거나 개인 사진 보관함에서 사진을 Soft Delete해도 이미 제출된 지원서와 기획사/제작사에 제공된 내용은 바뀌지 않습니다.

프로필 데이터의 계속 보관 동의와 이번 지원서 값의 프로필 갱신 선택은 구분합니다. 지원서에서 자동 채움 값을 수정해도 프로필을 자동 변경하지 않으며 두 조건이 모두 충족된 경우에만 기본·추가 정보를 갱신합니다. 제출 사진·영상 링크와 커스텀 답변은 갱신 범위에 포함하지 않습니다.

## 3. 만 14세 미만 아동

소셜 로그인 제공 범위만으로 나이를 확인할 수 없어 만 14세 미만 배우의 계정이 생성될 수 있습니다. 법정대리인 동의·확인 기능을 제공하기 전에는 지원서 제출 시 생년월일을 확인하고 만 14세 미만이면 제출과 서버 전송을 차단합니다. 계정 생성 단계의 아동 개인정보 처리 근거와 제한 방식은 실제 출시 전 전문가 검토를 완료합니다.

아역 지원 기능을 도입하는 경우 법정대리인 동의·확인 절차와 아동이 이해하기 쉬운 고지를 별도로 마련합니다.

## 4. 개인정보의 제3자 제공

운영팀은 배우가 선택한 기획사/제작사의 공고에 지원할 때 해당 지원서를 기획사/제작사에 제공합니다.

작성 중인 Draft는 현재 브라우저에만 있고 기획사/제작사나 서버에 제공하지 않습니다. 기획사/제작사는 최종 제출에 성공한 지원서 스냅샷만 열람할 수 있습니다.

| 제공받는 자 | 제공 목적 | 제공 항목 | 보유·이용기간 |
| --- | --- | --- | --- |
| 배우가 선택한 공고의 기획사/제작사(제출 화면에 정확한 명칭 표시) | 해당 공고·배역의 배우 심사, 오디션 일정·결과 연락과 동일 공연의 결원·대체 캐스팅 연락 | 배우가 해당 공고에 실제 제출한 기본 정보·추가 정보·사진·커스텀 답변과 첨부자료 | 전형 종료 후 30일까지 |

배우는 제3자 제공에 동의하지 않을 수 있습니다. 다만 지원서를 해당 기획사/제작사에 전달할 수 없어 그 공고에 지원할 수 없습니다. 기획사/제작사명·제공 항목·기간은 지원 시점의 동의 이력에 보관합니다.

기획사/제작사가 서비스 밖으로 다운로드·출력·복사한 정보는 기획사/제작사가 별도로 안전하게 관리하고 같은 기간에 파기해야 합니다. 운영팀은 삭제 요청을 기획사/제작사에 전달하고 처리 결과를 확인하지만 기획사/제작사의 외부 시스템을 직접 삭제할 수는 없습니다.

## 6. 개인정보의 국외 이전

수탁자의 리전과 해외 지원 접근을 포함해 국외 이전 여부를 출시 전에 확정합니다. 국외 이전이 있으면 이전받는 자, 국가·연락처, 항목, 목적, 시기·방법, 보유기간, 법적 근거와 거부 방법·효과를 구체적으로 공개합니다. 국외 이전이 없으면 “해당 없음”으로 확정합니다.

## 7. 보유기간과 파기

지원서·첨부파일·심사 기록의 보관·파기 기준은 다음과 같습니다.

1. 모든 배역·차수가 정상 마감되면 서버가 `allRoundsClosedAt`을 한 번 기록합니다.
2. 기획사/제작사의 일반 열람 권한은 `allRoundsClosedAt + 30일`에 차단하고, 기획사/제작사가 만든 다운로드·출력본도 같은 시점까지 파기하도록 요구합니다.
3. 정상 종료 시 플랫폼은 `purgeAt = allRoundsClosedAt + 90일`, `retentionBasis=NORMAL`을 기록하고 `purgeAt`에 운영 데이터를 파기합니다.
4. 기획사/제작사가 전형을 마감하지 않으면 `purgeAt = recruitmentEndsAt + 120일`, `retentionBasis=BACKSTOP`으로 정하고 `purgeAt`에 운영 데이터를 파기합니다.
5. 백스톱에서도 실제 전형 종료 시각인 `allRoundsClosedAt`을 임의로 만들지 않고, 남은 `PENDING` 배우를 합격·불합격으로 자동 결정하지 않습니다.
6. 브라우저 Draft는 서버 파기 대상이 아니다. 제출 성공 시 서비스가 해당 IndexedDB Draft를 삭제하며, 제출하지 않은 Draft의 직접 삭제·마감·장기 미사용 기준은 출시 전에 확정합니다.
7. 참조되지 않은 임시 업로드는 업로드 후 24시간 이내에 파기합니다.
8. DB, 객체 스토리지, 캐시, 검색 인덱스, 임시 다운로드와 파생본을 파기 범위에 포함합니다.
9. 백업은 90일 순환 방식으로 자동 만료합니다. 운영 데이터에서 삭제된 개인정보는 일반 업무에 복구·사용하지 않으며 최대 90일 안에 백업에서도 만료됩니다. 백업을 복원할 때에는 삭제 목록을 다시 적용합니다.
10. 법령에 따라 보존해야 하는 정보는 다른 개인정보와 분리해 해당 기간 동안만 보관합니다.

파기 결과와 실패·예외 사유는 파기대장에 기록합니다.

## 8. 정보주체의 권리와 행사 방법

이용자는 자신의 개인정보에 대해 열람, 정정·삭제, 처리정지와 동의 철회를 요구할 수 있습니다.

제출 완료 후 지원서를 일반적으로 수정하거나 지원 철회하는 기능은 제공하지 않습니다. 이는 개인정보 보호법상 권리 행사를 제한한다는 뜻이 아니며, 아래 경로로 정정·삭제·처리정지·동의 철회를 요구할 수 있습니다.

- 프로필: 서비스 화면에서 직접 열람·수정·삭제
- 지원서·첨부파일·심사 기록·제공 내역: contact@yesulin.art로 요청
- 회원 탈퇴: MVP 안내 화면 또는 contact@yesulin.art로 요청. MVP에는 즉시 탈퇴를 처리하는 Backend 기능이 없습니다.

운영팀은 로그인 계정과 필요한 추가 정보를 이용해 본인 또는 정당한 대리인 여부를 확인하고, 요청을 받은 날부터 10일 이내에 처리 결과 또는 제한·거절 사유와 이의제기 방법을 안내합니다.

기획사/제작사가 별도로 보유한 복사본은 기획사/제작사에도 삭제 요청이 필요할 수 있습니다. 운영팀은 필요한 경우 기획사/제작사와 수탁자에게 요청을 전달하고 결과를 확인합니다.

요청 이메일에는 이름, 회신 연락처, 요청 유형, 대상 계정·공고·지원서와 원하는 조치를 적어 주세요. 비밀번호, 인증코드, 주민등록번호, 계좌번호와 원본 사진·영상은 일반 이메일로 보내지 마세요. 다른 배우의 정보 노출, 오발송, 계정 탈취가 의심되면 이메일 제목에 `[긴급 개인정보]`를 표시해 주세요.

## 9. 안전성 확보조치

운영팀은 실제 서비스 출시 전에 다음 조치를 적용하고 검증합니다.

- 기획사/제작사 구성원별 개인 계정과 공고별 최소권한
- 접근권한 부여·변경·말소와 정기 검토
- 비밀번호 해시, 전송·저장 구간 암호화, HttpOnly Cookie 기반 Session과 CSRF 방어
- 지원서 상세·연락처·다운로드·출력에 대한 접속기록과 점검
- 원문 개인정보·쿠키·토큰·파일 URL을 일반 로그에 남기지 않는 허용목록 로깅
- 파일의 실제 형식·크기 검사, 악성파일 대응, EXIF 제거, 만료되는 인증 URL
- 개발·목 데이터와 실제 개인정보의 분리
- 백업 암호화, 접근 제한, 복구·재삭제 테스트
- 개인정보 유출·오발송·권한 오류 대응 절차

기획사/제작사 공유 운영계정은 실제 개인정보를 처리하는 운영 환경에서 사용하지 않습니다.

## 10. 쿠키·분석 도구

운영팀은 로그인 유지와 보안을 위해 JavaScript가 읽을 수 없는 HttpOnly Session Cookie를 사용합니다. 쿠키명·목적·만료기간, `Secure`·`SameSite` 속성과 브라우저별 차단 방법은 출시 전에 확정합니다. 필요한 쿠키를 차단하면 로그인 등 일부 기능이 제한될 수 있습니다.

인증 전 작성한 지원서와 사진은 소셜 로그인 화면 왕복, 새로고침과 브라우저 재실행 뒤 복구할 수 있도록 현재 브라우저 IndexedDB에만 보관합니다. 최종 제출 전에는 서버로 전송하지 않으며 다른 기기에서 이어 쓸 수 없습니다. Draft를 복원할 때 필수 동의 체크는 복원하지 않습니다. 제출 성공 시 해당 Draft를 삭제하며 공용 기기에서는 브라우저 데이터 삭제 기능을 이용해야 할 수 있습니다.

광고·맞춤형 추천 쿠키, Google Signals와 User-ID는 사용하지 않습니다. 운영팀은 이용자가 별도로 선택한 경우에만 Google Tag Manager를 통해 Google Analytics 4를 불러와 페이지 이용, 로그인 진입 위치와 지원 단계별 완료·오류를 분석합니다. 이름, 이메일, 전화번호, 지원서 답변, 사진·영상 URL과 사용자·공고·지원서 ID는 분석 이벤트에 넣지 않습니다.

분석 동의 전과 거부 상태에는 Google 분석 도구를 불러오거나 이벤트를 전송하지 않습니다. 동의 여부는 현재 브라우저의 로컬 스토리지에 저장하며, 화면 위쪽 머리말의 `분석 설정`에서 언제든 거부하거나 다시 동의할 수 있습니다. 동의를 철회하면 현재 브라우저의 `_ga`, `_gid`, `_gat` 계열 분석 쿠키를 삭제하고 페이지를 다시 불러옵니다. Google Analytics 쿠키의 기본 만료기간은 최대 2년이며 실제 이벤트 데이터 보유기간, 국외 처리 국가·법적 근거와 연락처는 정식 출시 전에 확정합니다.

## 11. 자동화된 결정과 공개 노출

현재 예술IN은 합격·불합격을 자동으로 결정하지 않습니다. 배역 조건 불일치는 참고 정보로만 표시하고 심사 결과는 기획사/제작사가 직접 결정합니다.

예술IN은 지원서를 검색엔진이나 일반 이용자에게 공개하지 않으며, 배우가 선택한 공고의 권한 있는 기획사/제작사 담당자에게만 제공합니다.
