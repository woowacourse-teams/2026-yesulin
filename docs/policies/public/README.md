## 공개 원칙

- 처리방침은 동의서가 아니라 상시 공개 문서다.
- 계정 생성에 필수인 정보는 계약 체결·이행을 근거로 처리방침에 고지하고 불필요한 필수 동의를 추가하지 않는다.
- 이용약관, 지원서 수집·이용, 기획사/제작사 제3자 제공은 목적에 맞게 구분한다.
- 프로필 저장은 별도 동의가 아니라 이용자가 요청하는 선택형 서비스 기능으로 제공한다.
- 화면에 표시한 목적·항목·기획사/제작사·보유기간·문안 버전과 동의 시각을 동의 이력에 저장한다.
- 지원서 수집·이용과 기획사/제작사 제3자 제공은 서버에서 별도 동의 이력으로 저장한다.
- 두 필수 동의는 이용자가 각각 표시할 수 있게 한다. 상단 `필수 항목 모두 동의`는 하위 두 입력을 함께
  변경하는 편의 기능이며 서버의 개별 동의 이력을 대체하지 않는다.
- 공개 문서가 약속하는 기능과 통제가 실제 코드·인프라·운영 절차에 존재하는지 출시 전에 검증한다.

## 게시 전 필수 구현 조건

- 최초 소셜 인증 후 배우 회원을 즉시 생성하지 않고, 10분 만료 가입 대기 상태에서 만 14세 이상을 확인한 뒤에만 회원·소셜 연결을 생성한다.
- 지원서 수집·이용과 제3자 제공 문서 버전·동의 시각·실제 기획사명·표시 항목·기간을 스냅샷으로 저장한다.
- 기획사/제작사 열람은 전형 종료 +30일, 미종료 시 모집 마감 +120일에 자동 차단하고 내부 메모를 파기한다.
- 배우가 지원 내역을 삭제하거나 탈퇴하면 지원서·첨부파일·확정 결과를 파기하고 백업은 최대 90일 안에 만료한다.
- 지원서와 연결되지 않은 업로드를 24시간 안에 삭제한다.
- 지원서 열람·다운로드 접속기록을 1년 이상 보관·점검한다.
- Sentry 조직 리전·보유기간, GA4 14개월 보유 설정과 수탁자 계약·약관을 운영 콘솔에서 재확인한다.
- 개인용 Gmail이 문의·권리 행사 메일을 처리하기에 적합한 위탁 계약·관리 조건을 제공하는지 검토하고, 충분하지 않으면 Google Workspace 등 사업용 메일로 전환한다.
