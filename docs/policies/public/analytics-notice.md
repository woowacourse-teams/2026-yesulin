# PostHog 방문 분석 안내

분석 안내 1.0 · 공고·시행일 2026-10-29 · 공개 위치 `/privacy/analytics`

공고와 서비스 기능이 어떻게 이용되는지 확인하고 개선하기 위해 PostHog를 사용한다. 방문 분석은 기본으로
켜져 있고, 이용자는 분석 설정에서 끌 수 있다. 꺼도 모든 서비스를 이용할 수 있으며 기존 거부 기록을 유지한다.
이 안내는 개인정보 처리방침의 방문 분석 안내를 보충한다. 1.1 보관 문안과 1.2의 다른 변경 시행일은 바꾸지 않는다.

## 수집하는 정보

- 브라우저 방문 식별자, 원래 회원 번호를 변환한 가명 계정 식별자, 방문 세션 식별자, 이용자 역할
- 공고 조회·첨부 클릭·오픈채팅 알림 유입, 공연 조회·예매 단계와 성공·실패, 공연사의 게시·관리 기능 이용
- PDF 업로드·추출·적용·저장 단계의 성공·실패, 처리 결과 확인까지의 시간, 개별 검토 이용 시간·저장 여부
- 행동 시각, 공고·공연·PDF 작업·심사 대상 식별자, 수량·제한된 오류 코드, 운영·개발 및 내부 테스트 구분

가명 식별자로 동일 계정의 행동을 연결하므로 완전한 익명 통계가 아니다. 이름·이메일·전화번호·PDF 원문·사진·
파일명·파일 주소·지원서 답변·심사 메모·판정 내용·현재 페이지 주소·제목은 보내지 않는다. 화면 녹화·자동 클릭·광고 추적은 사용하지 않는다.

## 전송과 보관

분석을 끄지 않은 상태에서 해당 행동이 발생하면 PostHog, Inc. 미국 리전으로 암호화 전송한다.
위탁 업무는 서비스 이용 흐름·재방문·기능 개선 효과 분석이다. 연락처와 처리 정보는
[PostHog 개인정보 처리방침](https://posthog.com/privacy)에서 확인할 수 있다.

이벤트 데이터는 현재 무료 요금제의 1년 보관 기준을 따른다(2026-10-29 관리 콘솔 확인).
브라우저 방문 식별자는 분석을 끄거나 해당 사이트 저장 데이터를 지울 때 초기화한다.
네트워크 전송 과정에서 IP가 처리될 수 있지만 분석 이벤트의 IP 저장과 IP 기반 위치 분석은 비활성화한다.

## 거부와 권리 행사

하단 ‘분석 설정’ → ‘분석 끄기’로 현재 브라우저의 이후 전송을 중단한다. 다른 기기·브라우저에서는 별도로
선택해야 하며 사이트 저장 데이터를 삭제하면 선택도 초기화될 수 있다. 거부만으로 이미 전송한 기록이 삭제되지는 않는다.
열람·삭제·처리정지 요청은 예술in 개인정보 보호 담당자(contact@yesulin.art)에게 보낸다.
