# 0011. 활성 공연사와 mock seed 이관 경계

## 계기

여러 공연사에 속할 수 있는 계정의 공연사 전용 요청 문맥, 날짜만 있는 모집 기간, 최신 제출 계약을 충족하지 못하는 기존 mock 지원서의 처리를 확정해야 했다.

## 결정

인증 세션에 검증된 `activeCompanyId`를 저장한다. 공연사 가입 및 단일 멤버십 로그인에서는 자동 선택하고, `PUT /api/v1/sessions/current/active-company`에서 소속을 검증해 전환한다. 공연·공고·배역 쓰기 요청은 body의 회사 ID를 신뢰하지 않고 활성 공연사 문맥과 소유 관계를 사용한다.

시드의 날짜 모집 시작은 Asia/Seoul 00:00을 포함하고, 종료는 종료일 다음 날 Asia/Seoul 00:00을 제외하는 범위로 해석한 뒤 UTC `DATETIME(6)`로 저장한다.

필수 거주지·동의 스냅샷·인증 Applicant가 없는 기존 지원서 73건은 이번 이관에서 제외한다. 공연사 1, 공연 5, 공고 5, 배역 16, 지원 양식 56건만 원본 ID를 보존해 이관한다.

## 이유

세션 문맥은 다중 소속을 지원하면서 요청마다 회사 ID를 위조하는 위험을 줄인다. 배타적 종료 시각은 날짜 전체를 오차 없이 표현한다. 불완전 지원서를 제출 완료로 보완하면 존재하지 않는 동의와 제출 사실을 조작하게 된다.

## 영향

시드 제외 항목은 [매핑 문서](../mock-seed-import.md)에 명시한다. 보완된 원본과 별도 결정 없이는 지원서·심사 데이터를 이관하지 않는다.
