# 0012. 배우 프로필 보관함

## 계기

기존 프로필은 경력·소개·사진·영상·추가 답변이 지원서 필드 구조에 따라 섞여 있었고, 사진은 네 장 교체 방식, 영상은 링크 한 개만 지원했다.

## 결정

배우 프로필의 내부 메뉴는 `기본정보`, `추가정보`, `사진`, `영상`으로 나눈다. 기본정보는 필수 8개, 추가정보는 기획사/제작사가 공고에서 선택하는 nullable 8개다. 자기소개는 추가정보에 포함하고 별도 소개와 공고별 추가 답변 메뉴는 두지 않는다.

사진 보관함은 최대 20장이고 한 장을 대표 사진으로 지정한다. 지원서 양식은 1~10장 범위에서 첨부 장수를 정한다. 영상 보관함은 YouTube 링크를 최대 10개 저장하고 임베드 미리보기를 제공한다. 사진·영상의 추가·삭제·순서 및 대표 사진 변경은 즉시 저장한다. 정보 입력은 명시적인 프로필 저장 버튼으로 저장한다.

## 이유

재사용 정보와 공고별 답변을 분리하고, 지원마다 같은 자료를 다시 등록하는 비용을 줄인다.

## 영향

프런트·MSW 프로필 응답은 정보 답변 외 사진·영상 보관함을 포함한다. 실제 파일 업로드와 개별 미디어 API는 백엔드 구현 전에 별도로 확정한다. 보관함 삭제는 Draft와 제출 스냅샷을 변경하지 않는다.
