# 공고 배역 참조

## 계기

공고 배역의 표시 정보는 공연 배역과 같지만 모집 조건은 공고별로 다르다. 이름·설명을 공고에도 저장하면
같은 정보가 중복되고 공연 배역 수정 시 어느 값을 보여줄지 모호해진다.

## 결정

공고 배역은 `performanceRoleId`와 모집 인원, 성별 조건, 최소·최대 나이만 소유한다. 이름·설명은 공연
배역을 조회해 응답에서 조립하며 참조 중인 공연 배역 삭제는 FK로 막는다. 같은 공연 배역을 다시 저장하면
공고 배역 ID를 유지한다. 복수 배역 지원을 허용할 때는 배역이 두 개 이상이어야 한다.

`AuditionRoleSelections`는 요청된 배역의 개수·중복·복수 지원 규칙을 생성 시 검증한다. JPA 일급 컬렉션
`AuditionRoles`는 하위 엔티티의 순서와 기존 ID 유지를 담당한다.

## 이유

공연 배역 표시 정보를 중복 저장하지 않으면서 공고별 모집 조건과 심사에 사용할 안정적인 공고 배역 ID를
유지한다.

## 영향

배역 API는 섹션 전체를 `PUT`한다. 공연 배역 삭제의 명시적인 비즈니스 오류와 게시 후 배역 변경 허용
범위는 지원서·게시 구현에서 참조 존재 여부와 함께 결정한다.
