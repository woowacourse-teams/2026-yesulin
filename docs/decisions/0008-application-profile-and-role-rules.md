# 0008. 지원서·프로필·배역 규칙

## 계기

복수 배역 지원, 프로필 재사용, 사진 보관과 심사 결과의 단위가 문서마다 다르거나 미결로 남아 과거 지원서가 프로필 변경의 영향을 받을 수 있었다.

## 결정

공고가 허용하면 한 지원서에서 여러 배역을 선택한다. 동일 계정은 같은 공고에 지원서를 하나만 제출하며 심사 결과는 `(지원서, 배역, 차수)`별로 관리한다. 별도의 자유 배역 타입은 두지 않고 공연사가 일반 배역 하나를 `자유`로 등록한다.

재사용 프로필에는 기본·추가 정보와 개인 사진 보관함을 두되 커스텀 답변은 제외한다. 프로필 저장 동의는 한 번에 받고, 지원서에서 수정한 값은 제출 화면에서 명시적으로 선택할 때만 프로필에도 저장한다. Draft와 제출 지원서의 사진은 개인 사진 보관함 삭제와 독립적으로 유지한다. 제출 시 정보·사진·답변·배역을 불변 스냅샷으로 보존한다.

로그인 전 작성 내용과 선택 사진은 임시 보관하고 인증 후 계정에 연결해 제출한다. 구체적인 로컬·서버 Draft 동기화 방식은 후속 [0009 결정](./0009-local-first-server-draft.md)을 따른다. MVP 공연사 역할은 `ADMIN`만 사용하고 `TEAM_MEMBER`는 향후 초대 기능과 함께 도입한다.

## 이유

배역별 독립 심사와 반복 지원의 편의성을 제공하면서 프로필 수정·사진 삭제가 과거 심사 자료를 바꾸지 않게 한다.

## 영향

지원자·공연사 흐름, API 계약, 개인정보 문서와 심사 식별 기준은 이 결정에 맞춘다. Draft 보관기간, 개인정보 정정본, 제출 재시도, 반복 항목 제한, 전형 종료 시각과 팀원 정책은 별도로 결정한다.
