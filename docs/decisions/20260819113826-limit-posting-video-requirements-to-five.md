# 공고 영상 요구사항 상한 5개

## 계기

공고 한 건에서 최대 10개의 영상을 요구하면 지원자의 제출 부담과 제작사의 한 지원서 검토 시간이 커진다. 심사 상세의 영상 목록도 한 화면에서 비교하기 어려워진다.

## 결정

기획사/제작사가 공고 지원 폼에 추가할 수 있는 영상 요구사항은 최대 5개다. 배우는 활성화된 각 요구사항에 YouTube 링크를 하나씩 제출한다. 배우 개인 영상 보관함의 최대 10개 정책은 바꾸지 않는다.

## 이유

공고별 제출량은 검토 가능한 범위로 제한하되, 배우가 여러 공고에서 재사용할 개인 영상 선택지는 기존대로 유지한다.

## 영향

공고 생성 UI와 저장 검증, 지원서 제출 검증, MSW fixture와 목표 API 계약이 같은 상한 5개를 사용한다. 심사 읽기 모델은 최대 5개의 `{ label, url }`을 요구 순서대로 반환한다.
