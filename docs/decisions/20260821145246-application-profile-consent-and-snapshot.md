# 지원서 프로필·동의·스냅샷

## 계기

프로필 보관과 제출값 갱신, 지원 동의와 파일 참조가 섞여 과거 지원서가 이후 변경의 영향을 받을 수 있었다.

## 결정

재사용 프로필은 기본 정보 8개와 추가 정보만 부분 저장한다. 프로필 계속 보관 동의와 이번 지원서 값의
프로필 갱신 선택을 분리하며, 커스텀 답변·제출 사진·영상 링크는 갱신하지 않는다. Draft 복원 시 동의와
갱신 선택을 초기화한다.

지원 UI는 수집·이용과 제3자 제공을 각각 필수 체크박스로 받고 서버에도 두 동의 이력을 각각 저장한다.
상단 전체 동의는 두 하위 체크박스를 함께 변경하는 편의 기능으로만 제공한다.

사진·영상은 배열 순서가 아니라 requirementId로 연결한다. 제출 시 기본·추가 정보, 모집 마감일 기준 만
나이, 답변, 배역명과 파일 참조를 불변 스냅샷으로 확정한다. 이후 프로필 수정이나 개인 사진 Soft Delete는
제출 지원서에 영향을 주지 않는다.

## 이유

재사용 편의와 동의 목적을 분리하고 심사자가 본 제출 당시 자료를 안정적으로 재현한다.

## 영향

동의 기록, 프로필 갱신, 파일 정제·참조, 지원서 제출 트랜잭션과 개인정보 문서를 함께 맞춘다.
