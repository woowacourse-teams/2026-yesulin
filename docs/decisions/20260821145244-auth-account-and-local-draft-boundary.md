# 인증·계정과 로컬 Draft 경계

## 계기

배우와 기획사/제작사 계정의 이메일 중복, 소셜 제공자 연결과 인증 전 지원서의 서버 전송 범위가 불명확했다.

## 결정

인증은 HttpOnly Cookie 기반 Session을 사용한다. 배우와 기획사/제작사는 같은 이메일이어도 별도 계정이며
유형 간 자동 병합하지 않는다. 배우 계정의 다른 소셜 제공자 연결도 이메일 일치만으로 처리하지 않고
이용자의 명시적 요청과 본인 확인을 거친다. MVP는 Company당 `ADMIN` 한 명만 둔다.

인증 전 지원서와 사진은 현재 브라우저 IndexedDB에만 저장한다. 최종 제출 과정 전에는 서버 Draft나
임시 파일을 만들지 않으며 다른 기기 이어쓰기를 지원하지 않는다. Draft 복원 시 동의 체크는 초기화한다.

만 14세 미만 계정은 생성될 수 있지만 법정대리인 동의·확인 기능 전에는 지원서 제출을 서버에서 차단한다.

## 이유

계정 오연결과 인증 전 개인정보의 서버 잔존을 줄이고 MVP 소유권 경계를 단순하게 유지한다.

## 영향

세션 보안 세부값, 소셜 연결 재인증, 나이 검증에 필요한 생년월일 수집과 최종 제출 파일 처리 계약을 구현 전에 확정한다.
