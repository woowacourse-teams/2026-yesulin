# 심사 완료 결과 필터와 차수별 일괄 작업

## 계기

검토 완료는 여러 심사 결과를 포함하지만 진입 즉시 합격자만 보여 전체 완료 대상을 파악하기 어려웠다. 차수와 결과에 따라 지원서를 인쇄하거나 연락처를 모아볼 운영 수단도 필요했다.

## 결정

심사 보드는 `검토 대기`와 `검토 완료`를 1차 작업 구분으로 사용한다. 검토 완료에 진입하면 완료된 지원자 전체를 먼저 표시하고, 합격·불합격·불참·기타는 별도 결과 조건으로 선택한다. 작업 탭과 결과 조건에는 인원수를 붙이지 않는다.

모든 차수의 검토 완료 화면에서 현재 보이는 지원자 전체를 인쇄하거나 연락처로 모아볼 수 있다. 결과 조건이 합격이면 합격자만, 전체이면 완료자 전체가 대상이며 검색·상세 조건도 반영한다. 개별 선택이 있으면 연락처 모아보기만 선택 대상을 우선한다. 인쇄는 기존 A4 양식을 재사용해 지원자마다 새 페이지로 출력한다.

## 이유

작업 완료 여부와 심사 결과를 분리하면 필터 의미가 명확해진다. 버튼에 현재 대상을 표시하면 잘못된 지원자를 인쇄하거나 연락하는 일을 줄일 수 있다.

## 영향

새 API 없이 현재 심사 보드 응답과 클라이언트 필터 결과로 일괄 작업 대상을 만든다. 배우용 지원서 인쇄 정책에는 영향을 주지 않는다.
