# 0011. 배우와 기획사/제작사 용어 사용

## 계기

화면에서 사용하던 `지원자`, `공연사`는 서비스의 실제 이용 주체를 충분히 구체적으로 설명하지 못했다.

## 결정

사용자에게 노출되는 역할 명칭은 `배우`, `기획사/제작사`로 통일한다. 화면 문구, 접근성 레이블, 메타데이터, 오류 메시지와 현재 정책·도메인 문서에 같은 용어를 사용한다.

내부 코드 식별자와 API 경로인 `applicant`, `producer`, `/applicants`, `/producers`는 기존 계약과 변경 범위를 안정적으로 유지하기 위해 바꾸지 않는다. `지원자격`처럼 역할 명칭이 아닌 단어도 유지한다.

브라우저에 표시하는 로그인 페이지 제목은 `예술in`으로 사용한다.

## 이유

화면의 이용 주체를 더 직관적으로 전달하면서도 라우트·타입·API 계약의 불필요한 변경을 피한다.

## 영향

새 UI와 문서는 `배우`, `기획사/제작사`를 기준으로 작성한다. 내부 영문 식별자는 사용자 문구로 그대로 노출하지 않는다.
