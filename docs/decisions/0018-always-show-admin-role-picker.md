# 관리자 배역별 지원 현황 진입 통일

## 계기

관리자 지원자 관리에서 공고의 모집 배역이 하나면 배역별 지원 현황을 건너뛰고 심사 보드로 바로 이동했다. 같은 메뉴가 공고별 배역 수에 따라 서로 다른 화면으로 열려 탐색 흐름과 정보 구조가 일관되지 않았다.

## 결정

관리자 `지원자 관리`와 사이드바의 공고 진입은 모집 배역 수와 관계없이 `/producers/postings/{postingId}` 배역별 지원 현황으로 이동한다. 관리자가 배역을 선택한 뒤 `/producers/roles/{roleId}` 심사 보드로 이동한다.

배우 공개 지원서에서 공고의 배역이 하나면 지원 배역 선택을 생략하는 기존 정책은 유지한다.

## 이유

공고 단위 진입 위치를 통일하면 관리자가 현재 공고와 배역별 지원·모집·검토 현황을 먼저 확인한 뒤 심사 대상을 선택할 수 있다.

## 영향

공고 요약과 관리자 탐색 트리에서 단일 배역 바로가기 필드는 사용하지 않는다. 기획사/제작사 흐름도는 모든 공고가 배역 선택을 거치도록 변경한다.
