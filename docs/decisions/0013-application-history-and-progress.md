# 0013. 내 지원서와 전형 공개

## 계기

내 지원서 목록이 제출 스냅샷만 보여 주고 상태를 `제출 완료`로 고정해, 작성 중 Draft와 복수 배역의 서로 다른 전형 진행 상황을 확인할 수 없었다.

## 결정

내 지원서는 현재 브라우저의 작성 중 Draft와 제출 완료 지원서를 구분해 표시한다. 작성 중 Draft는 이 기기에서 이어 쓰며 제출 성공 시 삭제한다.

동일 계정은 같은 공고에 지원서 하나만 제출한다. 복수 배역 선택은 중복지원이 아니며 목록에는 `지원서 1개`, 선택한 배역 수와 배역 이름을 함께 표시한다.

전형 진행은 배역별로 표시한다. 기획사/제작사가 검토 중인 결과는 배우에게 공개하지 않고, 해당 배역·차수가 마감된 뒤 확정 결과만 내 지원서 목록과 상세에 반영한다. 내부 메모는 항상 비공개다.

## 이유

Draft와 제출 스냅샷의 공개 범위를 구분하면서, 한 지원서 안에서도 독립적으로 진행되는 배역별 심사를 정확하게 전달한다.

## 영향

배우용 지원서 응답은 배역별 공개 전형 상태를 포함한다. 서버 Draft 목록과 다른 기기 동기화는 별도 계약이 필요하다. 지원서 상세의 인쇄 기능은 제공하지 않는다.
