# 로컬 우선 서버 Draft 동기화

## 계기

로그인·가입 왕복과 브라우저 종료 뒤 입력을 복구하면서도, 향후 앱과 다른 기기에서 지원서를 이어 쓰고 매 입력마다 서버 요청이 발생하지 않게 할 필요가 있다.

## 결정

로그인 전·후 모두 작성 내용과 사진을 IndexedDB에 먼저 저장하고 서버 Draft와 지연·묶음 동기화한다. 로그인 또는 회원가입이 완료되면 현재 브라우저의 Draft와 파일을 계정에 자동 연결한다. 계정에 같은 공고의 Draft가 있으면 최신 수정본이 이전 Draft 전체를 덮어쓴다. 최종 제출 전 Draft는 공연사에 공개하지 않는다. 제출 성공 전까지 IndexedDB 사본을 유지한다.

회원가입이 최종 제출 과정에서 완료되면 연결한 Draft를 곧바로 제출한다. 최종 제출은 서버 시각 기준 모집 중일 때만 허용하고, 서버 Draft를 불변 지원서 스냅샷으로 확정한다. 마감된 Draft는 전형 종료 후 별도 기간까지 보관한 뒤 삭제한다.

## 이유

IndexedDB는 로그인 왕복·새로고침·브라우저 재실행을 복구하고 서버 Draft는 웹·앱·다른 기기의 이어쓰기를 지원한다. 로컬 우선 동기화는 입력마다 발생하는 서버 요청을 줄인다.

## 영향

인증 전 Draft의 식별·접근 통제, 최신 수정본 판정, 동기화, 사진 업로드, 보관·삭제와 최종 제출 계약이 필요하다. 개인정보 고지 시점과 정확한 보관기간은 별도로 결정한다.
