# 0003. 문서와 에이전트 컨텍스트

## 계기

결정의 배경이 대화에만 남으면 이후 팀원과 에이전트가 같은 논의를 반복하거나 과거 결정을 되돌릴 수 있다.

## 결정

공통 결정은 번호 파일로 짧게 기록하고 상세 내용은 관련 명세에 둔다. 중요한 결정은 `agent-required: true`로 표시하고 `AGENTS.md`와 `CLAUDE.md`에서 필독하게 한다.

## 이유

`계기·결정·이유·영향`만 남기면 적은 토큰으로 판단 맥락을 복원할 수 있다.

## 영향

구현과 문서 갱신은 같은 작업 단위로 처리한다. 상세: [문서 운영 원칙](../README.md)
