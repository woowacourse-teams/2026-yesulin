# 시각 기반 결정 파일명

## 계기

결정 파일의 다음 순번을 여러 작업자가 동시에 선택하면 PR rebase마다 파일명과 목록 충돌이 발생한다.

## 결정

파일명은 `yyyyMMddHHmmss-kebab-case.md`로 만들며 시각은 UTC를 사용한다. 목록은 시각순으로 유지하고 순번을 재사용하지 않는다. 기존 순번 파일도 최초 반영 커밋 시각 기반 이름으로 이관한다.

## 이유

중앙에서 다음 번호를 예약하지 않아도 독립적인 작업이 충돌 가능성이 낮은 이름을 만들 수 있다. 주제 suffix가 같은 초에 생성된 서로 다른 결정을 구분한다.

## 영향

새 결정을 추가할 때 `date -u '+%Y%m%d%H%M%S'`로 prefix를 만들고 [결정 기록 목록](./README.md)에 연결한다. 대체 문서는 번호가 아닌 파일 링크로 지정한다.
