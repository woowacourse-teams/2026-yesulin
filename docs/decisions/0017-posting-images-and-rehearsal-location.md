# 공고 이미지와 연습 장소

## 계기

공고 목록을 대표하는 이미지와 모집 일정·연습 정보를 담은 본문용 이미지의 역할이 섞여 있었고, 공연 장소와 공고별 연습 장소의 소유 범위도 명확하지 않았다.

## 결정

공고의 대표 이미지는 공연 포스터를 초기 스냅샷으로 복사하되 공고에서 교체할 수 있다. 공고는 대표 이미지와 별도로 공개 상세 본문에 표시할 선택 상세 이미지 하나를 가진다. 공연 장소는 공연에서만 관리하고, 공고는 선택적인 연습 장소명과 구조화된 `rehearsalVenueAddress`를 가진다. 주소는 `roadAddress`, `detailAddress`, `zonecode`, nullable `latitude`·`longitude`로 구성하고 공연 장소와 같은 주소 검색·지도 UI를 사용한다.

## 이유

목록·공유 미리보기와 긴 안내 콘텐츠는 화면 비율과 갱신 목적이 다르다. 두 이미지를 분리하면 대표 이미지의 일관성을 유지하면서 모집 일정표 같은 상세 안내를 그대로 제공할 수 있다. 공연 장소를 공고마다 복제하지 않으면 같은 공연 안에서 장소가 어긋나는 문제를 줄일 수 있고, 시기마다 달라질 수 있는 연습 장소는 공고가 소유하는 편이 자연스럽다.

## 영향

공고 생성·공개 조회 계약에 상세 이미지와 연습 장소가 추가된다. 공고 생성 뒤 일반 정보 수정은 기존 결정대로 허용하지 않고 일정만 수정한다. 실제 이미지 업로드 식별자는 백엔드 연동 전에 별도로 정한다.
